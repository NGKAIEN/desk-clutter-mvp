# v05 最小现场验收

目的：确认当前固定机位、桌面和照明下，MVP 可以完成一次可信的操作闭环。
这不是传感器精度认证。按 70 分原型的范围，不要求原始栏毫无噪点。

## 准备

- [ ] 关闭其他相机程序，确认相机/桌面没有移动，灯光保持不直射问题区域。
- [ ] 选择已检查的标定，在 v05 中显式传入 `--calibration`；记下候选文件名和 SHA-256。
- [ ] 保留 10mm 网格、10mm 高度下限、20mm 内缩，Temporal ON。
- [ ] 清空有效 ROI 内的物品；不要仅凭已有占用率基线把物品扣掉。

如果试用可选局部高度模式：按 [空桌参考指南](../guides/BACKGROUND_HEIGHT_GUIDE.md) 清空**整个** ROI、
采集新参考，再在 v05 中显式传 `--background`。记下参考哈希，保持 Temporal ON；
此时使用参考内的局部门槛，不再使用绝对 10mm 下限。不要用有电脑的诊断报告作为参考。
下面五场景必须用采集之外的新数据完成；采集图好看不算验证通过。

## 五个场景

每个稳定场景观察约 10 秒，按 S 留一份 PNG + JSON。瞬间手伸入桌面不作为稳定状态验收。
以下数值是本 MVP 的建议验收约定，不是行业标准。

| 场景 | 期望表现 | 待填写 |
| --- | --- | --- |
| 空桌 | 主分数大部分时间有效且接近 100（建议 ≥99）；没有持续假区域/PCA 轴；允许原始栏少量红点 | 当前机位快照约 99%–100%；面积门槛挡住小噪声方向，长期误报率未测 |
| 放入电脑等可检测物体 | 主分数下降，稳定栏出现占用；方向明确的长条/矩形区域给出主轴，方形可 N/A | 用户确认区域连续、主要边界轻微抖动；快照方向可输出 |
| 同位置旋转 | 清楚的主轴大体跟随；同一可见面积的物体不因“斜放”被额外扣分，分数只随检测到的面积变化 | 多位置/朝向快照有角度；仍有抖动/N/A，同位置连续旋转精度未验证 |
| 拿走物体 | 在处理帧率正常、自由桌面重新可见时约 1 秒内开始恢复，不留下持续的假区域 | 等待后恢复已观察；约 1 秒这一延迟目标未测量 |
| 大范围观测不足 | 当前已分类率下降后分数 N/A；不能把灰色变成绿色或显示完美分数 | 软件合成测试通过，现场未测 |

观测不足测试不需要拔插 USB；可用现成的低覆盖场景，或在不接触设备的前提下短暂挡住视野。
物理遮挡也可能产生有效近处深度，不一定等同“缺测”；应以界面的当前覆盖率和灰色区域为依据。
若无法安全制造现场缺测，可把这一项标为现场未测，同时附上 `--demo-scene missing --headless` 的软件验证，
不要把合成结果记成硬件通过。

补充操作：暂停时主分数 N/A；恢复后重新积累。按 T 关闭时间稳定时主分数 N/A。
按 R 不得改写标定。S 导出应与当前画面一致，不覆盖上一次结果。

## 如何决定是否收尾

- 五个场景满足上述范围，就冻结本版参数，整理一段演示并收尾。
- 偶发原始红点但稳定栏无假物体：先接受，不继续叠加算法。
- 持续假区域、放入后长时间漏检、拿走后残留：保留对应报告，针对具体问题修复。
- 评分频繁 N/A：先看稳定覆盖率、当前覆盖率、Held 哪项触发，不直接降低门限来隐藏问题。
- 手机/薄片漏检、反光、接触物体分不开、完整语义整洁度：记入后续范围，不用它们无限扩大本次验收。

## 当前证据与待办

此前用户提供的 v04 空桌截图显示稳定占用 0.0%、区域 0、PCA 轴 0；这是一个机位下的单次结果。
v05 复用该检测核心，但评分和现场交互仍需本清单验收。
自动测试涵盖合成的放入→旋转→拿走→缺测→恢复；不等于现场已通过。
后续真实电脑试用发现原绝对模式有漏检/跳动，因此新增了可选空桌参考模式；
新模式仍待当前机位独立验证，不能仅凭以前的空桌截图宣布这一问题已经解决。
不要把本文件的“未测”提前改成“通过”。

以上段落是此前阶段背景。2026-11-02 的后续现场观察已更新到上表：局部模式、
相同参考、Temporal ON，PCA 比值 1.5、方向面积 50cm²。不能用这些参数证明默认绝对模式也同样有效。
