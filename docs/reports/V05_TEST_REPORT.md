# v05 验证记录

日期：2026-11-01。范围：软件离线验证与合成图像检查，不是现场验收或传感器精度测试。

后续增加可选局部空桌高度模式，两环境累计 **164 项**通过；见
[追加验证记录](BACKGROUND_HEIGHT_TEST_REPORT.md)。下文 131 项与公开白名单复制测试是该新增模式之前的记录。

## 自动测试

```bash
.venv/bin/python -m unittest discover -s tests -v
python3 -m unittest discover -s tests -v
```

两个现有环境均通过 **131 项**：v04 50 项、高度诊断 27 项、多帧标定 27 项、v05 新增 27 项。

另将公开白名单文件复制到独立临时目录，不带 `.venv`、个人标定、历史采集或输出，
使用系统现有依赖再次通过 131 项测试，并成功生成 headless 演示报告。
这验证代码不依赖本机私有标定/数据，不等同于新机器或干净环境安装。

v05 覆盖：

- 空桌 100、全占用 0、已知分母、未知与排除带不算空闲。
- 当前帧缺测但历史仍已知时立即停止有效评分；稳定覆盖、当前覆盖和 Held 门限及边界值。
- 启动预热、暂停、关闭时间稳定、无有效 ROI、非法状态/形状的处理。
- 小占用斑块仍计入分数；PCA 方向无效不能让真实占用从分数里消失。
- 空桌→放入→旋转→移除→缺测→恢复的合成连续流程。
- headless 模式不打开相机或 GUI；缺测和诊断模式导出的分数为 JSON null。
- 实时入口必须显式指定标定；缺失文件在打开相机前报错。
- 模拟实时按键、只读加载、报告与画面保存、拒绝覆盖、异常时释放采集与 GUI 资源。

## 合成演示结果

默认 10mm 网格，固定种子 4，各场景独立预热 30 帧：

| 场景 | 空闲度 | 候选区域 | 结果 |
| --- | ---: | ---: | --- |
| empty | 100.0 | 0 | READY |
| objects | 93.24 | 2 | READY，长方形有方向、方形 N/A |
| rotated | 93.31 | 2 | READY，长轴约 60°，面积量化导致分数小幅差异 |
| removed | 100.0 | 0 | READY；独立运行即空桌，连续移除另由生命周期测试覆盖 |
| missing | null / N/A | 0 | 覆盖率不足，不显示完美分数 |

已目视检查默认演示、缺测画面，以及当前斜四边形 ROI 上的合成布局；输出尺寸 1128×794。
README 使用合成矩形桌面示例，不公开个人桌面照片。

## 已测环境与安装边界

| 项目 | 项目虚拟环境 | 系统现有 Python |
| --- | --- | --- |
| Python | 3.14.4 | 3.14.4 |
| NumPy | 2.5.3 | 2.3.5 |
| OpenCV 导入版本 | 5.0.0 | 4.10.0 |
| 平台 | Linux x86_64 | 同一主机 |

项目环境另装有 pyrealsense2 2.58.4.10922、open3d-cpu 0.20.0；本轮没有打开相机，
也未重新执行四角硬件标定。实时 SDK 与 Open3D 不参与无相机测试。

依赖检查发现项目环境中已有的 `launch-ros` 缺少 `osrf-pycommon`、`pyyaml`；
它们不是本项目的依赖，本轮未修改或补装。系统 Python 没有 pip 模块。
因此没有声称整个共享环境的依赖检查干净，也没有声称在全新机器上完成安装。
requirements 是兼容范围，发布前仍应在目标平台的干净环境按 README 安装一次。
