## 当前现场结论

固定机位和同一空桌参考下，用户观察到电脑形成连续区域、主要边界轻微抖动；
拿走后快照空闲度恢复约 99%–100%。最新三张电脑快照输出方向，新增 50cm² 方向面积门槛
明确挡住一个 15cm² 噪声块的假方向，用户反馈噪点方向减少。
这足以支持有限范围的 70 分原型演示，不等于方向连续稳定或测量精度认证。
角度仍可能抖动/N/A、不同位置检测面积不同、现场缺测与恢复延迟未系统测量。

## 干净安装环境

独立临时虚拟环境：Linux x86_64 / Python 3.12.14。
从 PyPI 按 requirements.txt 安装，得到 NumPy 2.5.4、opencv-python 5.0.0.93。
没有安装 RealSense SDK 或 Open3D，不连接相机。原项目虚拟环境没有改动。
仅对验证进程屏蔽 PYTHONPATH/PYTHONHOME、关闭用户 site，避免终端的 ROS 包注入。
安装后环境仅见 pip 与上述两个依赖，pip check 通过。
