# Desk Clutter MVP v0.5 - 发布说明草稿

范围：固定机位下的桌面可见占用、空闲度代理和候选区域 PCA 方向。
这是可操作、可解释的最小原型，不是通用物体识别或主观整洁度模型。
本文件是发布材料，存在文件不代表已经建立 GitHub Release。

## 可演示的功能

- 无相机合成演示与 headless PNG/JSON 导出；不需要个人标定、RealSense SDK 或 Open3D。
- 四角标定、RGB/俯视图对照、只读高度诊断、多帧平面细化和独立验证。
- 三状态网格（桌面/占用/未知）、桌边内缩、单格支持与时间稳定。
- 可选空桌局部高度参考，减轻固定机位下的薄电脑漏检。
- 空闲度 = 已知格中的空闲比例；低观测质量、暂停或关闭时间稳定时不输出有效分数。
- 连通候选区域和 PCA 方向；方向输出与占用统计分离。
- 可选方向门槛 `--pca-ratio 1.5 --min-pca-area-cm2 50`，用于当前机位的试验配置。

默认仍是绝对高度模式、PCA 比值 2.5、额外方向面积限制关闭。
局部模式必须显式传自己的 `--background`；每个新机位都需要自己的标定与空桌参考。
试验参数不自动覆盖默认值，也不意味着适用于其他桌面。

## 当前证据

用户现场结果支持：电脑区域可检出、静止时主要边缘抖动、移除后回到接近空桌。
方向面积门槛确实拦住一个 15cm²、比值 4.14、跨度 6.3cm 的噪声区域；
三份电脑快照仍能输出方向。用户反馈小噪声假方向减少。
不能据快照声称连续角度稳定、精确物体面积、恢复延迟或跨机位泛化已验证。

软件与发布检查结果见 [发布验证记录](docs/reports/RELEASE_READINESS.md)。
历史测试报告是各自日期的阶段记录，不是当前全部验收结论。

## 已知限制

- 换位置、反光、远端噪声和轮廓缺损可能造成方向抖动或 N/A。
- 检测区域不是真实完整物体轮廓；同一电脑在不同位置的检测面积和分数可能变化。
- 小于方向面积门槛的真实物体也不提供方向，但仍参与占用统计。
- 排除带中的真实占用不统计；未知不当作空闲。
- 不识别物体身份，不跨帧跟踪，不补全遮挡，不保证薄手机检测。
- 实时模式依赖相机、驱动、设备权限和对应 Python wheel；仅离线测试不证明硬件兼容。
