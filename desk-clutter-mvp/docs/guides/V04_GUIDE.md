# v04：稳定网格与 PCA 方向实验

这一版只验证“基础稳定处理 + PCA 主方向”，**还没有整洁指数**。
v03、`desk_debug_v2.py`、现有 `calibration.json` 和基线不作修改。

## 启动

在项目目录、已安装依赖的 Python 环境中运行：

```bash
python desk_orientation_v04.py
```

默认读取脚本同目录的 `calibration.json`。首次使用请先运行
`python desk_debug_v2.py` 完成桌面标定，再退出该程序以释放相机。
v04 不导入 v2，也不重新拟合或保存标定。默认在原标定四边形的四条边向内排除 20mm，
仅在剩下的有效检测区计算占用和 PCA；这不需要重新标定。更新代码后请退出旧进程再启动。

需要 NumPy、带桌面窗口支持的 OpenCV；实时模式额外需要 `pyrealsense2`、
可用的 RealSense 相机及设备权限。实时流为 `640 x 480 @ 30 FPS`。

没有相机也可以检查程序流程：

```bash
python desk_orientation_v04.py --demo
```

这是**合成数据**，不是相机录制，不证明真实桌面的检测性能。
包含长方形、正方形、随机缺测和异常点。按 `N` 在 0°、30°、90° 之间切换长方形方向。

没有桌面显示环境时，保存一张合成演示图后退出：

```bash
python desk_orientation_v04.py --demo --snapshot /tmp/desk_v04_demo.png
```

为保护已有文件，同名截图不会被覆盖，重复运行请换一个输出名。

## 三栏怎么看

三栏均只显示有效检测区内的分类；边缘排除带统一用紫色纹理表示。

1. **RAW**：当前帧按旧版“任一点超高就标红”的规则分类；没有点数过滤或时间过滤，但有边缘排除。
2. **STABLE**：先检查每格点数与占比，再做时间确认。按 `T` 关闭时间过滤时，
   中栏仍保留单帧点数/占比过滤，标题变为 FRAME。
3. **REGIONS**：对中栏的占用连通区域做 PCA；外接框只用于显示，不用于计算角度或占用面积。

- 绿色：支持这里是桌面的观测。
- 红色：支持这里存在高于阈值物体的观测。
- 深灰：未知，包括点不足、分类证据冲突、超出高度范围或没有观测。
- 短暂保留的历史状态仍用正常绿/红色，不再逐帧变暗；是否保留查看 `Held` 数值。
- 黄色边界：原始标定 ROI；青色边界：内缩后的有效检测区。
- 紫色纹理：边缘排除带，不是桌面、不是物体，也不是未知深度；不参与统计或 PCA。
- 右上角 `Temporal ON / OFF`：当前时间稳定开关，同时显示下一次按 `T` 的结果。
- `Classified now`：当前帧通过支持门槛的格子比例，不等于原始深度像素有效率。
- `Stable known`、`Held`：已知状态格数、保留状态格数分别除以有效检测区格数。
- `Occupied / ACTIVE ROI`：占用格数除以有效检测区格数，分子分母均排除边缘。
  不是整洁分，也不表示未知格子被确认为空桌面；不同内缩宽度下的比例不能直接当作同范围比较。
- `Active`：有效检测区格数 / 原始标定区格数；括号表示保留了多大比例的检测范围。
- `Raw object cells in excluded band ... (ignored)`：排除带中原始规则标红的格数，仅作诊断，
  不显示为红色、不送进时间确认、连通区域或 PCA；不是“已确认的误检数”，真实物体也会包含其中。

## 默认参数

所有算法默认值集中在 `Settings`。常用项可从命令行覆盖，完整参数见 `--help`。

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `--grid-mm` | 10 | 运行时网格；不修改标定文件里保存的大小 |
| `--edge-margin-mm` | 20 | 沿四条标定边向内排除的物理宽度；0 关闭排除 |
| `--min-height-mm` | 10 | 高度下限；本版不保证薄手机检测 |
| `--max-height-mm` | 400 | 高度上限 |
| `--min-cell-points` | 3 | 至少这么多点支持同一种分类 |
| `--support-fraction` | 0.60 | 支持点数占该格有效采样点数的比例；桌面与物体票互斥 |
| `--window` / `--votes` | 5 / 3 | 最近最多 5 帧，需要至少 3 帧同类证据；启动时也需要 3 帧 |
| `--hold-seconds` | 0.50 | 没有同类支持时的最长保留时间；旧投票同样按时间过期 |
| `--min-region-cm2` | 8 | 区域过滤使用实际面积，不是固定格数 |
| `--pca-ratio` | 2.5 | 大/小特征值比的试验门槛，不是准确率 |

这些值是初始实验设置，不是经过真实桌面验证的最优值。点数不足的远处区域可能更多地显示未知；
这不代表它们变得更准确。不要一次改很多参数。

例如要对照之前的 3mm 实验（更敏感，也更易误检）：

```bash
python desk_orientation_v04.py --min-height-mm 3
```

## 优先处理边缘误检

默认先用 20mm（2cm）排除带。距离按桌面 `(u, v)` 的真实边计算，不是缩小画面外接矩形，
因此斜着的四边形也适用。保留的必须是整个格子都落在内缩边界内：10mm 网格下显示会有阶梯，
实际排除宽度可能比设置略大，而不是逐像素的精确 20mm 线。

对照时只改这一个参数，退出程序后重新启动：

```bash
# 默认 2cm
python desk_orientation_v04.py --edge-margin-mm 20

# 关闭排除，用于同场景对照
python desk_orientation_v04.py --edge-margin-mm 0

# 仅当边缘噪声带确实更宽时，尝试 4cm
python desk_orientation_v04.py --edge-margin-mm 40
```

排除在连通区域提取之前生效，不只是隐藏 PCA 线。即使这条带内出现很长、很稳定的红色噪声，
也不会靠它产生区域和方向。排除带既不算占用，也不算空桌面；设置过大导致没有有效检测格时直接报错，
不会悄悄恢复整张桌面检测。

代价是**放在排除带内的真实物体也会被忽略**；跨越边界的物体只保留内侧部分，面积和方向可能受影响。
这是 MVP 的检测范围收缩，不是修好了深度测量。若红色仍深入青色边界内，先检查标定平面、相机是否移动及
噪声覆盖范围，不要无限加宽排除带。桌面内部的偏差、反光和缺测不由这一步解决。

## 稳定处理与 PCA

- 每格保留“未知 / 桌面 / 物体”三种状态。未知不投空桌面票。
- 满足多数票后确认新状态；有物体的位置连续获得足够桌面票时，会清除物体状态。
- 暂时缺测时可以短暂保留；超过保留时间则转为未知。时间单位是秒，不假定实际处理达到 30 FPS。
- 不做深度补洞、不做 SDK 空间/时间滤波、不做跨片段合并；当前稳定发生在网格层。
- 对每个区域的占用格中心，在桌面 `(u, v)` 坐标中等权计算二维协方差和第一主轴。
- 方向显示为相对**标定四边形最长边**的 `0°～180°` 轴向角，不是 RGB 画面角度，也不区分头尾。
- 区域主轴跨度不足 5cm、特征值比不足门槛时，显示 `N/A`，区域本身仍保留。
- `r` 是形状方向性，不是方向正确概率。缺失轮廓和离群点也可能产生“很细长但方向错误”的区域。
- 区域编号按当前面积排序，**不是跟踪 ID**，没有跨帧角度平均。最多绘制 16 个区域，统计保留全部合格区域。

## 按键

默认启动为 **Temporal ON**，第一次按 `T` 是关闭，不是开启；关闭后更容易出现单帧跳动。
保持 ON 做日常观察，OFF 只用于对照。命令行 `--no-temporal` 可使启动状态为 OFF。

| 按键 | 功能 |
| --- | --- |
| `T` | 切换时间稳定；同时清空历史，避免旧状态混入对照 |
| `R` | 清空历史，不改标定 |
| 空格 | 暂停/继续画面；继续时重新积累历史 |
| `S` | 在脚本目录保存带时间戳的截图 |
| `N` | 合成演示中切换角度；实时模式不生效 |
| `Q` / Esc | 退出并释放相机 |

## 测试与人工验收

不连接相机的自动测试：

```bash
python -m unittest discover -s tests -p 'test_orientation_v04.py' -v
```

真实桌面仍需人工验收：

1. 固定相机与照明，保持 `Temporal ON`，先检查原来误检的空桌边：紫色排除带内不应出现红色分类或 PCA 区域；
   观察红色是否仍延伸到青色边界内，记录 `ignored` 格数。必要时用 0mm / 20mm 同场景对照。
2. 在青色边界内放置方向明显的长方形物体，确认排除边缘后内部物体仍能检测，静止时主轴较稳。
3. 相对桌边依次摆成约 0°、30°、90°，确认主轴大致跟随。
4. 放一个近正方形物体，方向应为 `N/A`，但区域仍可显示。
5. 按 `T` 对照并检查右上角 ON/OFF；拿走物体，确认恢复桌面或在缺测时超时转未知，没有长期残影。
6. 观察 `Classified now` 和 `Held`，不要只因为画面不闪就认定数据准确。短暂保留状态不应再出现额外亮暗变化，
   但真实分类改变或保留超时仍会改变颜色。

闪烁减少不等于系统偏差被修正：固定位置的误检、台灯反光、远距离缺测、遮挡和相连物体仍是已知限制。
真实相机角度误差、帧率和闪烁改善幅度须现场测量，不由合成测试替代。

如果远端空桌红色已经深入有效检测区，不要只继续加宽排除带。
可先退出 v04，按 [空桌高度诊断指南](HEIGHT_DIAGNOSTIC_GUIDE.md) 采集一段高度、波动与覆盖率，
区分持续偏高、动态波动及缺测；诊断不会修改本程序或标定。
