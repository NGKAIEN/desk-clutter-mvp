# v05 可选空桌高度参考

目的：在固定机位下，减轻局部高度偏差和逐帧抖动造成的薄电脑漏检。
这是针对 70 分 MVP 的可选检测方式，不是物体识别、形状补全或传感器精度保证。
默认 v05、v04、原标定及 PCA 都保留。所有命令在项目根目录运行。

## 1. 为什么需要它

原模式把点到理想桌面的距离与 10mm 比较。假设某格空桌长期测为 −4mm，
放入物体后测为 +4mm：它只比理想平面高 4mm，但比同格空桌高了 8mm。
只降低全局阈值会同时放大其他位置的噪声；只做状态投票无法恢复一直低于阈值的物体。

新模式分别保存每个网格的空桌偏差及噪声门槛，运行时比较**相对空桌的高度变化**。
这个差值仍是深度测量结果，不应直接称为物体真实厚度。

## 2. 采集真正的空桌参考

1. 退出其他相机程序。固定相机、桌面及照明，保持台灯不直射问题区域。
2. **清空整个标定 ROI，包括电脑、电线等物品。** 不要用有物体的诊断报告生成参考。
3. 选择已独立验证的标定文件。若当前使用多帧候选，以下两个命令都必须传该候选文件，
   不能在采集时用原标定、检测时换候选。

```bash
.venv/bin/python desk_height_background.py --calibration calibration.json
```

窗口刚打开仅预览，不采集。确认空桌、画面稳定后按 **C**：采集默认 5 秒，自动保存，
终端打印新路径 `height_backgrounds/background_时间戳/background.json`。按 **Q** 退出并释放相机。
终端也会打印带正确标定、参考与网格参数的完整启动命令，可在退出后直接复制运行。
按 C 的含义是操作者确认空桌；程序不能自动识别一个静止薄电脑是否被误当成桌面。

每次另建目录，包含 `background.json`、网格样本 `samples.npz`、`capture.png`。
既不覆盖原标定，也不自动激活参考；默认目录已加入 `.gitignore`。
截图是采集数据的统计图，不是独立验证通过的证明。

若采集拒绝，终端给出原因。先检查清空、灯光、移动和覆盖率，不把无效格强制改成零。
低帧数可用 `--seconds 10` 重试；极慢处理导致短窗口内不足 3 帧时，仅延长总时长也无效。
工具支持 3–15 秒、`--grid-mm`、`--edge-margin-mm`、`--output-dir`。

## 3. 明确开启新模式

把目录名换成刚刚保存的实际目录：

```bash
.venv/bin/python desk_status_v05.py --calibration calibration.json \
  --background height_backgrounds/background_时间戳/background.json
```

界面出现 `LOCAL delta gate`，左栏标题变成 `CURRENT: local delta / cell median`。
左栏是当前帧；中栏额外经过高度中位数和状态投票。右栏仍为区域和 PCA，方向可以 N/A。

程序检查标定文件完整字节的 SHA-256、网格、内缩、深度范围和最小点数。
不匹配时，在打开相机前拒绝加载；甚至只修改标定 JSON 排版也需要重新采集参考。
这些检查不能发现“相机移动了但标定文件没变”：移动相机需重做标定及参考；桌面、灯光或设备改变也需重采参考。

- 不传 `--background`：回到原来的 10mm 绝对高度模式。
- **T**：同时关闭/开启高度中位数和状态投票，关闭时分数 N/A；首次验收保持 ON。
- **R**：重置两层时序历史，参考不变；不是重新学习空桌。
- **Space**：暂停；恢复时重置历史。
- **S**：保存 PNG + JSON，包含模式、参考哈希及门槛信息。
- 不需要编辑 `calibration.json`。局部模式不能用 `--min-height-mm 3` 等修改门槛，避免参数表面改变、实际未生效。

## 4. 当前算法及默认值

| 环节 | 规则 |
| --- | --- |
| 单帧采样 | 每格至少 3 个有效深度点，取有符号高度中位数；**替代**原 60% 物体点支持规则 |
| 空桌偏差 | 多帧单格高度中位数的中位数；只在明确空桌采集时建立，运行中不自动学习 |
| 相对高度 | 当前单格高度 − 保存的同格空桌偏差，单位 mm |
| 短时滤波 | 最近最多 5 帧的相对高度中位数，至少 3 个有效样本，样本年龄 ≤0.25 秒；当前帧必须有有效数据 |
| 单格门槛 | `max(6mm, Q99(abs(滤波后的空桌残差)) + 2mm)`；门槛 >12mm 的格不启用 |
| 基准质量 | 至少 60 帧；单格观测覆盖 ≥90%，滤波后有效帧数 ≥max(30, 75%采集帧数)，偏差绝对值 ≤20mm；有效基准须覆盖 ≥90% active ROI |
| 占用判定 | 滤波后的相对高度严格大于该格门槛，且低于 400mm（可用原 `--max-height-mm` 改上限） |
| 空桌与未知 | 非占用且相对高度绝对值 <10mm 才为空桌；参考无效、当前缺测、异常负值/超高保持未知 |
| 状态稳定 | 继续用 5 帧中 3 票，短暂保留最多 0.5 秒；ROI、连通区域和 PCA 不改 |

噪声门槛从同一批空桌数据估算，是启发式规则，**不是 99% 准确率或未来误报率保证**。
连续中位数窗口重叠，后续投票也不是相互独立的统计样本。
噪声高的位置门槛会更高，因此 8mm 物体也可能漏检；不能用滤波凭空恢复完全缺失的深度。
两层稳定会增加响应延迟；帧率不足时宁可未知。真实延迟应在实际机位测试。

质量门控仍检查当前数据：`Classified NOW` 来自未做时间滤波的当前单格差值分类，
不是历史滤波结果。稳定状态与当前分类不一致也计入 Held。
缺测时历史可能短暂保留，但不会靠它继续冒充高质量实时分数。
空闲度仍为 `100 × FREE/(FREE+OCCUPIED)`，不是语义整洁度；READY 也不代表轮廓完整。

## 5. 必须另做一轮验证

采集结束、退出采集工具后，启动新模式，依次做：

1. **空桌 10 秒**：稳定栏应接近全绿，无持续假物体，空闲度建议 ≥99；按 S 保存。
2. **放入电脑 10 秒**：稳定占用应增加，相比旧模式轮廓缺口/跳动是否减少；按 S。
3. **旋转电脑**：区域足够长且形状稳定时方向大体跟随；方形或残缺区域允许 N/A。
4. **拿走电脑**：自由桌面重新可见后应恢复，不应把电脑持续留在图上。

如果只空桌好看而电脑仍检不出，不能算通过；如果降低门槛后空桌持续误报，也不能算通过。
首次先给出空桌和放电脑两份结果即可，再决定是否值得继续调参。
有问题请提供 `view.png`、`report.json` 及所用参考的 `background.json`；不要重新在放着电脑时按 C。
