Desk Clutter MVP

> 历史实验与标定流程说明。当前 MVP 的推荐入口、评分定义、安装和复现方式见 [README.md](../../README.md)。

基于 Intel RealSense 深度相机的桌面杂物检测原型。项目把深度图转换为三维点云，使用 RANSAC 拟合桌面平面，再将点投影到桌面坐标系和二维网格中，用于观察桌面占用率、检测物体区域，并估计物体的长边方向。

当前版本更偏向实验和诊断工具：程序会打开实时窗口，参数主要写在 Python 脚本顶部，尚未封装成稳定的命令行应用。

## 功能概览

- 检查 RealSense RGB 与深度流是否正常。
- 实时查看深度点云。
- 对单帧点云使用 RANSAC 检测最大平面。
- 交互式标定桌面区域（ROI），并保存到 `calibration.json`。
- 将桌面划分为约 `1 cm × 1 cm` 的网格，实时估计杂物占用率。
- 保存“干净桌面”基线，并显示当前占用率相对基线的变化。
- 从连通区域估计物体数量、区域框和长边方向。

## 工作原理

1. RealSense 输出 `640 × 480 @ 30 FPS` 深度帧。
2. `pyrealsense2` 将深度帧转换为三维点云，并过滤 `0.20–2.00 m` 范围外的点。
3. Open3D 使用 RANSAC 拟合桌面平面。
4. 根据平面法向量建立桌面坐标轴 `u/v`，并计算每个点相对桌面的高度 `h`。
5. 高度在当前入口的物体高度上下限之间的点被视为物体候选；不同旧版入口的阈值不同，v04 默认 `10–400 mm`，并在启动时和界面上显示实际值。
6. 物体点被映射到二维网格，网格中被占用的单元占比即为可见桌面占用率。

注意：占用率是基于相机当前可见点和标定 ROI 的几何占用率，不是物体体积，也不等同于完整的 3D 物体识别结果。

## 环境要求

### 硬件

- Intel RealSense 深度相机。
- 稳定的 USB 连接。
- 一张在相机视野内、尽量平整且无遮挡的桌面。

### 软件

- Python 3.10+（建议使用项目内的 `.venv`）。
- RealSense SDK / `pyrealsense2`。
- NumPy。
- OpenCV。
- Open3D。

在项目目录中创建并启用虚拟环境：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install numpy opencv-python open3d pyrealsense2
```

如果 `pyrealsense2` 无法安装或无法发现设备，请先确认 RealSense SDK、设备权限和 USB 连接；这部分依赖操作系统和相机驱动，不能仅由本项目解决。

## 快速开始

所有命令都建议从项目根目录执行：

```bash
cd desk-clutter-mvp
source .venv/bin/activate
```

### 1. 检查相机

```bash
python experiments/test_camera.py
```

窗口左侧显示 RGB，右侧显示伪彩色深度图。按 `Q` 退出。

### 2. 查看实时点云

```bash
python experiments/pointcloud_live.py
```

该脚本只启用深度流，在 Open3D 窗口中实时显示点云。关闭窗口或结束窗口事件即可退出。

### 3. 测试 RANSAC 平面检测

```bash
python experiments/ransac_test.py
```

脚本等待相机稳定后处理一帧点云，打印检测到的平面方程、平面点数和比例，并将平面与其他点分别显示。

### 4. 标定桌面并运行调试视图（推荐流程）

```bash
python desk_debug_v2.py
```

首次运行或选择重新标定时：

1. 等待 RANSAC 完成。
2. 在 **Recalibrate 标定阶段**，左边显示相机实拍，右边默认显示**同一张照片按桌面平面展开的俯视画面**，保留桌面纹理和物品外观。移动鼠标到任一图上，青色十字和连线会指出另一图中的对应位置；左图的青色边框标明右图覆盖的大致范围。直接在**左侧照片中**沿桌面边界点击四个角点，黄色边界同步显示在两侧，右侧仍支持选点。
3. 检查两个视图中的边界后，按 `Enter` 保存。按 `U` 或退格撤销上一个角点，`R` 清空重选，`F` 重新拍摄并拟合桌面，`Q` 退出。四点重复、共线或无法形成有效四边形时不会保存。
4. 程序将平面、坐标轴和四边形 ROI 写入 `calibration.json`。
5. 进入实时模式后，按 `B` 保存当前占用率为干净桌面基线，按 `Q` 退出。

如果已存在 `calibration.json`，程序会提示：

- `L`：加载已有标定，直接进入运行画面。
- `R`：重新标定，进入照片选角界面；需要重新选桌面时应输入 `r` 并回车。

标定窗口默认使用照片对照，按 `V` 可在右侧的照片视图和红绿点阵诊断视图之间切换。点阵模式中，绿色为检测到的平面，红色为桌面上方物体点。标定后进入实时占用率窗口，右侧仍显示占用率点阵。黄色表示所选 ROI 及角点编号；照片对应位置通过 RealSense 相机内外参转换，原有占用率计算方式保持不变。

- `O`：开关左侧照片上的绿色平面叠层；标定时默认关闭以保留实拍外观，需要核对 RANSAC 平面时打开。黄色 ROI 和角点编号继续显示。
- `V`：仅在标定窗口中切换右侧照片/点阵视图。鼠标悬停不会增加角点，选满四角后仍可用鼠标联动检查对应位置。
- 右侧照片是按拟合的桌面平面展开的图像，不是新的相机视角；高出桌面的物体可能拉伸，源照片没有覆盖的部分留空。在点阵模式下，鼠标连线表示同一桌面平面位置，高物体的点阵可能与其照片轮廓存在位移。
- `S`：保存整张对照图到脚本所在目录，文件名为 `desk_compare_calibration_<时间>.png` 或 `desk_compare_live_<时间>.png`。
- 标定使用同一次采集的静态 RGB/深度图，便于准确点选；按 `F` 更新照片并清空选点。照片点击通过相机内外参转换为射线，与已检测平面求交后得到桌面坐标，因此桌角处缺少深度像素时也能选点。选择期间请保持相机和桌面不动。
- 如果绿色叠层落在墙面或地面上，说明 RANSAC 找错了平面；调整相机取景，让桌面成为主要可见平面，再按 `F` 重新检测。照片选点不会自动纠正一个错误的平面。

基线写回 `calibration.json`，因此重新标定或覆盖基线前建议备份该文件。已有标定可选择 `L` 加载并查看照片对照。

### 5. 运行自动 ROI 的占用率版本

```bash
python experiments/desk_occupancy.py
```

该脚本每次启动时自动使用 RANSAC 拟合桌面，并根据平面点的百分位范围建立矩形 ROI，然后实时显示占用率。按 `Q` 退出。

它与 `desk_debug_v2.py` 的区别是：不会读取交互式四边形 ROI，也不会保存标定结果；适合快速验证算法，但对桌面边界和异常点更敏感。

### 6. 查看区域与方向诊断

先确保已有 `calibration.json`，然后执行：

```bash
python desk_orientation_v03.py
```

该脚本以只读方式加载标定，检测物体候选连通区域，并对长宽比较明显的区域估计长边方向。

- `Q`：退出。
- `M`：切换形态学处理。
- `S`：保存当前诊断截图到 `v03_debug.png`。

### 7. v04：稳定网格与 PCA 主方向实验

保留上述 v03 作为对照，新增独立入口：

```bash
python desk_orientation_v04.py
```

默认使用 10mm 网格和 10mm 物体高度下限，只读加载标定；沿桌边内缩 20mm，
排除带不参与占用统计、连通区域或 PCA（`--edge-margin-mm 0` 可关闭对照）。
黄色是原标定边界，青色是有效检测边界，紫色纹理是排除带；带内真实物体同样会被忽略。
三栏显示有效检测区的原始分类、经过点数支持与多帧确认的网格，以及 PCA 主轴。
时间稳定默认 ON，右上角显示开关状态；第一次按 `T` 是关闭。`R` 清空历史，
空格暂停，`S` 保存截图，`Q` 退出。方向不明确的区域显示 `N/A`。
这一版尚未计算整洁指数，也不会自动修复反光、补齐物体轮廓或跟踪物体身份。

无相机合成演示：`python desk_orientation_v04.py --demo`。
参数、图例、自动测试及人工验收步骤详见 [V04_GUIDE.md](V04_GUIDE.md)。

### 8. 远端空桌误检：高度诊断

先退出相机程序，清空要检查的桌面并固定相机/照明，再运行：

```bash
python desk_height_diagnostic.py
```

准备好后按 `C` 采集 5 秒，显示高度中位数、时间波动和有效观测比例。
完成后点击误检位置查看数值，按 `S` 保存含选点的报告，`Q` 退出。
报告保存到 `height_diagnostics/` 的独立时间戳目录；不修改标定或现有检测逻辑。
原始 ROI 的排除带也参与诊断，缺测不当作零高度。使用和解读见 [HEIGHT_DIAGNOSTIC_GUIDE.md](HEIGHT_DIAGNOSTIC_GUIDE.md)。

### 9. 多帧空桌平面细化：候选与独立验证

已有四角标定大体正确、相机未动时，可使用独立入口检查整体高度偏差：

```bash
python desk_calibrate_multiframe.py
```

先退出其他相机程序，保持不直射桌面的灯光固定，并清空整个 ROI（包括电脑和线材）。
按 `C` 采集 5 秒，单独保存候选标定；再按 `V` 采集另一段 5 秒数据，
用同一批新点对比旧/新平面。点击远端问题位置查看数值，`S` 保存选点截图，`Q` 退出。
报告保存在 `plane_calibrations/` 的时间戳目录，原 `calibration.json` 不改写，候选不自动启用。
这一步不改变 PCA、边缘排除或检测阈值，也不能靠换平面消除逐帧噪声。
先看独立验证报告，确认后再用 v04 的 `--calibration` 显式试用候选。
详细步骤及限制见 [MULTIFRAME_CALIBRATION_GUIDE.md](MULTIFRAME_CALIBRATION_GUIDE.md)。

## 标定文件

`calibration.json` 主要包含：

- `normal`、`d`：桌面平面方程。
- `origin`：桌面坐标系原点。
- `u_axis`、`v_axis`：桌面平面内的两个坐标轴。
- `polygon_uv`：在桌面坐标系中的四边形 ROI。
- `grid_size`：网格边长，当前默认为 `0.01` 米。
- `baseline`：可选的干净桌面占用率基线。

这是与当前相机位置和桌面摆放相关的标定结果。相机移动、俯仰角明显变化或桌面位置变化后，应重新运行 `desk_debug_v2.py` 完成标定。

## 常见问题

### 找不到相机或启动失败

确认：

- RealSense 设备已连接且没有被其他程序占用。
- 当前用户有访问 USB/相机设备的权限。
- `pyrealsense2` 已安装在当前 Python 环境中。
- 相机支持并能稳定输出 `640 × 480` 深度流。

可先运行：

```bash
python experiments/test_camera.py
```

### 标定窗口中的点云很少或噪声很大

让桌面保持静止，确保桌面在相机视野内，并等待相机预热。避免透明、反光或超出深度量程的表面；必要时调整脚本顶部的深度范围和 RANSAC 阈值。

### 占用率不稳定

当前实现按可见网格单元计数，容易受到深度噪声、遮挡、物体边缘和 ROI 大小影响。可以先在稳定的空桌面上按 `B` 建立基线，再结合 `M` 形态学开关观察区域检测效果。

### `desk_orientation_v03.py` 提示缺少标定

先运行 `desk_debug_v2.py`，完成四点 ROI 标定并生成 `calibration.json`，再启动方向诊断脚本。

## 当前限制与后续方向

- 占用率和物体区域仍基于深度点云；RGB 仅用于照片对照，尚未进行物体类别识别。照片中的叠层在遮挡边缘可能存在偏差。
- ROI 和阈值依赖相机安装位置，缺少统一配置文件或命令行参数。
- 占用率是可见表面网格占用率，不能可靠表达被遮挡区域。
- 当前脚本以实时窗口为主，尚未提供 API 或持久日志系统；v04 已提供无相机自动测试，验证范围见 [V04_TEST_REPORT.md](../reports/V04_TEST_REPORT.md)。
- 可继续加入时序滤波、深度空洞修复、稳定的物体跟踪、真实桌面边界检测和结果导出。
