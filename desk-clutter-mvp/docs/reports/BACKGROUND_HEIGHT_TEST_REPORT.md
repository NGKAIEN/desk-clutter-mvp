
两个现有环境都通过 **164 项**：原 131 项，加 `test_height_background.py` 的 33 项。
环境版本沿用 [V05_TEST_REPORT.md](V05_TEST_REPORT.md)；不是全新环境安装验证。

新增覆盖：

- 高度中位数预热、孤立尖峰、当前缺测、超龄、慢帧率、重置与非法输入。
- 带符号空桌偏差、6mm 门槛下限、噪声提高门槛、过大噪声/偏差拒绝。
- 参考点数/观测覆盖/有效比例要求；个别无效参考格始终未知，不补零。
- 精确标定哈希、网格、内缩、采样范围一致性；拒绝普通诊断报告、损坏数组和合成 LIVE 参考。
- 合成例：空桌 −4mm、放物体后 +4mm，绝对模式判空桌，局部模式按 +8mm 判占用。
- 当前缺测时，即使历史仍有状态，也立即停止有效评分；当前与滤波结果冲突计入 Held。
- 独立于训练噪声的空桌→8mm 物体→旋转→移除→缺测流程；PCA 继续工作。
- headless 不使用相机/GUI；按 T/R/暂停恢复同时管理两层历史，T OFF 不平滑。
- C 之前不采集；C 采集后另存；参考/截图/样本可读、哈希可核对、不覆盖、退出释放资源。
- 显式记录限制：静止平面状物体可能通过数值筛选，程序不能替操作者确认空桌。

默认模式既有的 131 项回归测试保持通过。报告格式升为 schema v2，新增 `detection`，
不改变默认分数公式；局部模式标明绝对高度下限与点支持比例不再适用。
